# COVID-19 India Analysis Dashboard

## Project Overview
Developed an interactive Tableau dashboard to analyze COVID-19 trends across India, including active cases, deaths, recoveries, vaccination growth, and state-wise statistics.

## Tech Stack
- Tableau
- Data Modeling
- Geographic Mapping
- Dual Axis Charts
- Data Visualization

## Key Features
- Active Cases Analysis
- Vaccination Growth Tracking
- Fatality Rate Monitoring
- State-wise Geographic Mapping
- Age Group Analysis
- Trend Analysis Dashboard

## Dashboard Preview

![Dashboard](dashboard.png)

## Key Insights
- Tracked infection and recovery trends over time.
- Analyzed vaccination progress across different periods.
- Identified relationships between vaccination growth and mortality rates.
- Visualized state-wise COVID-19 impact using geographic mapping.

## Impact
Identified inverse correlation between vaccination rates and mortality, enabling data-driven insights into pandemic progression.
